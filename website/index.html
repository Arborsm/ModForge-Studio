工坊能力

不是五个分散工具，是一条连贯流水线。

从安装到检视，从草稿到导出，每一步都落在同一套桌面运行时里，减少在文件夹与网页之间来回切换。

01

模组库与启动流

扫描本地 SMAPI 模组、启用/禁用、安装备份与包管理。启动器侧还能对接 Nexus 发现、下载队列与更新比对。

Installed Library Download queue Update keys
02

资源与世界数据

检视地图、事件、角色、物品、建筑与存档。把游戏世界当目录来读，而不是当黑盒。

03

Content Patcher 创作

结构化草稿、变更注册表、动态 Token、自定义地点与导出指纹。面向真实补丁管线，而不是纯文本堆砌。

04

事件图与脚本诊断

事件命令按对话、移动、视觉、逻辑等分类编排；舞台预览与诊断把时间轴和错误原因放在同一视野。

  • Event Timeline
  • Script diagnostics
  • Continuity sheet

Workbench

三栏创作桌：灵感、心跳、世界圣经。

Studio Desk 把近期灵感放在左侧，项目心跳与工作区入口放在中间，世界规则、Token 与导出中心放在右侧。从 Project Lobby 进入地图、角色、建筑、物品、事件或模组工作区，各自独立编辑，又共享同一项目上下文。

Launcher

模组、更新与下载任务，收在同一个壳层视图。

Library 管本地安装库；Discover 搜 Nexus 并排队下载；Updates 用 UpdateKeys 对照线上版本；Configuration 管理游戏路径、Nexus API 与诊断。状态优先：启用数、缺失依赖、队列进度和路由健康一目了然。

  • Pack presets 与隐藏模组
  • 安装备份与摘要
  • Nexus 网络诊断与 API Key

桌面优先

Linux、macOS、Windows 同一套 Rust 后端能力。

前端 React 工作区；Linux 走 Electron 宿主，macOS / Windows 走 Tauri v2。宿主命令统一经 Host Runtime 调度，业务层不直接碰平台 API。

Windows

Tauri 打包 · MSI / NSIS

macOS

Tauri v2 桌面路径

Linux

Electron + Rust sidecar
