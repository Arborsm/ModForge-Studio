# MediaFacet

## Description

Facet fields specific to the media query.

## Fields

| Input Field | Description |
| --- | --- |
| `category` - [[String!]](../types/String.md) | Facet on category. |
| `type` - [[String!]](../types/String.md) | Facet on media type. |
| `gameId` - [[String!]](../types/String.md) | Facet on game ID. |

## Example

```json
{
  "category": ["xyz789"],
  "type": ["xyz789"],
  "gameId": ["abc123"]
}
```
