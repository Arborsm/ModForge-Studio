# CommentRevision

## Description

A comment revision.

## Fields

| Field Name | Description |
| --- | --- |
| `body` - [String!](../types/String.md) | The content of this revision. |
| `createdAt` - [DateTime!](../types/DateTime.md) | Time of when this revision was first created. |
| `id` - [ID!](../types/ID.md) | ID of the object. |
| `updatedAt` - [DateTime!](../types/DateTime.md) | Time of when this revision was last updated. |

## Example

```json
{
  "body": "xyz789",
  "createdAt": "2007-12-03T10:15:30Z",
  "id": "4",
  "updatedAt": "2007-12-03T10:15:30Z"
}
```
