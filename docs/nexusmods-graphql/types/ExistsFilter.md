# ExistsFilter

## Description

Filter for checking if a field exists (is not null) or does not exist (is null)

## Fields

| Input Field | Description |
| --- | --- |
| `op` - [FilterComparisonOperatorExists!](../types/FilterComparisonOperatorExists.md) | Comparison operator: EXISTS or NOT_EXISTS. |

## Example

```json
{"op": "EXISTS"}
```
