# Endorsement

## Description

An Endorsement

## Fields

| Field Name | Description |
| --- | --- |
| `modelId` - [BigInt!](../types/BigInt.md) | Id of endorsed entity |
| `modelType` - [String!](../types/String.md) | Type of endorsed entity |
| `status` - [String!](../types/String.md) | Endorsement status: abstained/endorsed |
| `userId` - [Int!](../types/Int.md) | The database ID for this endorsement. |
