# BlockedMod

## Description

A mod blocked from earning donation points

## Fields

| Field Name | Description |
| --- | --- |
| `id` - [String!](../types/String.md) | The database ID for this blocked_mod. |
| `isBlocked` - [Boolean!](../types/Boolean.md) | True if the mod is blocked from earning donation points |

## Example

```json
{"id": "abc123", "isBlocked": true}
```
