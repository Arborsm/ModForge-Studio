# ModAnalyticsByMonthNode

## Description

The mod analytics for a specific month

## Fields

| Field Name | Description |
| --- | --- |
| `month` - [Int!](../types/Int.md) | Month |
| `totalDownloads` - [BigInt!](../types/BigInt.md) | Total downloads |
| `uniqueDownloads` - [BigInt!](../types/BigInt.md) | Unique downloads |
| `year` - [Int!](../types/Int.md) | Year |

## Example

```json
{"month": 123, "totalDownloads": {}, "uniqueDownloads": {}, "year": 123}
```
