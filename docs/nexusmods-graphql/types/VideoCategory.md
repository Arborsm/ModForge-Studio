# VideoCategory

## Description

An video category

## Fields

| Field Name | Description |
| --- | --- |
| `date` - [Int](../types/Int.md) | Unix timestamp of category creation |
| `id` - [ID!](../types/ID.md) | The database ID for this video category. |
| `name` - [String!](../types/String.md) | Name of this category |

## Example

```json
{"date": 987, "id": 4, "name": "abc123"}
```
