# WalletList

## Description

A list of wallets. Users must have admin access.

## Fields

| Field Name | Description |
| --- | --- |
| `filteredCount` - [Int!](../types/Int.md) | Number of wallets being filtered |
| `totalCount` - [Int!](../types/Int.md) | Total number of wallets in the system |

## Example

```json
{"filteredCount": 123, "totalCount": 123}
```
