# UpdateImageInput

## Description

Defines a Image Update request object

## Fields

| Input Field | Description |
| --- | --- |
| `id` - [ID!](../types/ID.md) | Image ID |
| `title` - [String](../types/String.md) | Image title |
| `altText` - [String](../types/String.md) | Alternative text |

## Example

```json
{
  "id": "4",
  "title": "abc123",
  "altText": "abc123"
}
```
