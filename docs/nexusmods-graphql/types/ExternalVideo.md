# ExternalVideo

## Description

An external video.

## Fields

| Field Name | Description |
| --- | --- |
| `embedUrl` - [String!](../types/String.md) | The embed URL for the video. |
| `id` - [ID!](../types/ID.md) | The external video ID. |
| `platform` - [ExternalVideoPlatform!](../types/ExternalVideoPlatform.md) | The platform where the video is hosted. |
| `thumbnailUrl` - [String!](../types/String.md) | The thumbnail URL for the video. |
| `title` - [String!](../types/String.md) | The title of the video. |

## Example

```json
{
  "embedUrl": "xyz789",
  "id": 4,
  "platform": "youtube",
  "thumbnailUrl": "abc123",
  "title": "xyz789"
}
```
