# PaymentEntity

## Description

An entity to represent either an account or a bank

## Fields

| Field Name | Description |
| --- | --- |
| `id` - [Int!](../types/Int.md) | The database ID for this payment entity. |
| `label` - [String!](../types/String.md) | Name of this entity |
| `type` - [String!](../types/String.md) | Type of entity |

## Example

```json
{
  "id": 123,
  "label": "xyz789",
  "type": "abc123"
}
```
