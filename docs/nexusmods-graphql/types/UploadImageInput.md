# UploadImageInput

## Description

Defines a Image Upload request object

## Fields

| Input Field | Description |
| --- | --- |
| `id` - [ID!](../types/ID.md) | Image UUID |
| `contentType` - [String!](../types/String.md) | Image content type |
| `title` - [String](../types/String.md) | Image title |
| `altText` - [String](../types/String.md) | Alternative text of the image |

## Example

```json
{
  "id": 4,
  "contentType": "abc123",
  "title": "abc123",
  "altText": "xyz789"
}
```
