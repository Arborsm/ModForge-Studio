# GameVersion

## Description

A version of a specific game.

## Fields

| Field Name | Description |
| --- | --- |
| `id` - [ID!](../types/ID.md) | Unique ID for referring to this version in future queries |
| `reference` - [String!](../types/String.md) | Game version reference |

## Example

```json
{
  "id": "4",
  "reference": "abc123"
}
```
