# CsamDeletionRequestCDNFilePathResult

## Description

A CSAM Deletion Request file path result from a CDN

## Fields

| Input Field | Description |
| --- | --- |
| `path` - [String!](../types/String.md) | The file path that was processed |
| `status` - [String!](../types/String.md) | The status of the file path processing (e.g., "deleted", "failed", "not_found") |
| `message` - [String!](../types/String.md) | A message about the processing of the file path |

## Example

```json
{
  "path": "xyz789",
  "status": "abc123",
  "message": "xyz789"
}
```
