# CompositeDomainWithIdInput

## Description

Defines a Mod request using Game Domain and Mod ID

## Fields

| Input Field | Description |
| --- | --- |
| `gameDomain` - [String!](../types/String.md) | Game domain |
| `modId` - [Int!](../types/Int.md) | Mod ID |

## Example

```json
{"gameDomain": "xyz789", "modId": 987}
```
