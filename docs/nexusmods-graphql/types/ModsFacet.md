# ModsFacet

## Description

Facet fields specific to the mods query.

## Fields

| Input Field | Description |
| --- | --- |
| `gameDomainName` - [[String!]](../types/String.md) | Facet on game domain name. |
| `gameName` - [[String!]](../types/String.md) | Facet on game name. |
| `gameId` - [[String!]](../types/String.md) | Facet on game id. |
| `adult` - [[String!]](../types/String.md) | Facet on adult. |
| `languageName` - [[String!]](../types/String.md) | Facet on language. |
| `status` - [[String!]](../types/String.md) | Facet on status. |
| `categoryName` - [[String!]](../types/String.md) | Facet on category. |
| `tag` - [[String!]](../types/String.md) | Facet on tag. |
