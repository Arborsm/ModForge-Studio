# CollectionManifest

## Description

The JSON manifest that defines a collection

## Fields

| Input Field | Description |
| --- | --- |
| `info` - [CollectionManifestInfo!](../types/CollectionManifestInfo.md) | Manifest information |
| `mods` - [[CollectionManifestMod!]!](../types/CollectionManifestMod.md) | List of mod resources for the manifest |

## Example

```json
{
  "info": CollectionManifestInfo,
  "mods": [CollectionManifestMod]
}
```
