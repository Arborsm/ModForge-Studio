# CommentModerationStatus

## Description

Enum for available moderation states: "none", "hidden", "locked"

## Values

| Enum Value | Description |
| --- | --- |
| `none` | The comment is not under moderation. |
| `hidden` | The comment cannot be viewed. |
| `locked` | The comment cannot be interacted with. |

## Example

```gql
"none"
```
