# AgeVerificationId

## Description

An age verification ID and created at date pair.

## Fields

| Field Name | Description |
| --- | --- |
| `createdAt` - [DateTime!](../types/DateTime.md) | The date the external verification ID was created. |
| `externalVerificationId` - [String!](../types/String.md) | An external age verification ID. |

## Example

```json
{
  "createdAt": "2007-12-03T10:15:30Z",
  "externalVerificationId": "abc123"
}
```
