# DonationReport

## Description

Report Type defined by the Wallet app.

## Values

| Enum Value | Description |
| --- | --- |
| `UNIQUE_DOWNLOADS` | Unique Download report |
| `I20_GAME_ADJUSTED` | Interaction-based, game-adjusted report |
| `I20_GAME_POOLS` | Interaction-based report with DP bucketed by game |

## Example

```gql
"UNIQUE_DOWNLOADS"
```
