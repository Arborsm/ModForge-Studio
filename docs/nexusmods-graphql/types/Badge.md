# Badge

## Description

A badge

## Fields

| Field Name | Description |
| --- | --- |
| `automated` - [Boolean!](../types/Boolean.md) | Whether the badge is automated. |
| `description` - [String!](../types/String.md) | Description of the badge. |
| `id` - [Int!](../types/Int.md) | ID of the badge. |
| `name` - [String!](../types/String.md) | Name of the badge. |

```json
{
  "automated": false,
```
