# BooleanFilterValue

## Description

A boolean value E.g. true or false

## Fields

| Input Field | Description |
| --- | --- |
| `value` - [Boolean!](../types/Boolean.md) | Boolean Value |
| `op` - [FilterComparisonOperator](../types/FilterComparisonOperator.md) | Comparison operator for value. |

## Example

```json
{"value": false, "op": "EQUALS"}
```
