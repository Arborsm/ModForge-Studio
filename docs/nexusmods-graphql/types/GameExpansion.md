# GameExpansion

## Description

Represents a game expansion (DLC)

## Fields

| Field Name | Description |
| --- | --- |
| `gameId` - [ID!](../types/ID.md) | The ID of the game that the expansion belongs to |
| `id` - [ID!](../types/ID.md) | The ID of the game expansion |
| `name` - [String!](../types/String.md) | The name of the game expansion |

## Example

```json
{
  "gameId": 4,
  "id": "4",
  "name": "abc123"
}
```
