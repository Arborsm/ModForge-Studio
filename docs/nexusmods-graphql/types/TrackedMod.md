# TrackedMod

## Description

Represents a user's tracking of a mod

## Fields

| Field Name | Description |
| --- | --- |
| `gameId` - [ID!](../types/ID.md) | The ID of the game that the tracked mod belongs to |
| `modId` - [ID!](../types/ID.md) | The ID of the mod that is tracked |
| `userId` - [ID!](../types/ID.md) | The ID of the tracking user |

## Example

```json
{
  "gameId": "4",
  "modId": "4",
  "userId": 4
}
```
