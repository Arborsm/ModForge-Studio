# GameEdge

## Description

An edge in a connection.

## Fields

| Field Name | Description |
| --- | --- |
| `cursor` - [String!](../types/String.md) | A cursor for use in pagination. |
| `node` - [Game](../types/Game.md) | The item at the end of the edge. |

## Example

```json
{
  "cursor": "xyz789",
  "node": Game
}
```
