# UserEdge

## Description

An edge in a connection.

## Fields

| Field Name | Description |
| --- | --- |
| `cursor` - [String!](../types/String.md) | A cursor for use in pagination. |
| `node` - [User](../types/User.md) | The item at the end of the edge. |

## Example

```json
{
  "cursor": "abc123",
  "node": User
}
```
