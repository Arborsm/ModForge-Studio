# TrackModMutationPayload

## Description

Autogenerated return type of TrackModMutation.

## Fields

| Field Name | Description |
| --- | --- |
| `success` - [Boolean!](../types/Boolean.md) | True if the request to track the mod was successful, or if the mod was already tracked. |
| `trackedMod` - [TrackedMod!](../types/TrackedMod.md) | Tracked mod entry. |

## Example

```json
{"success": true, "trackedMod": TrackedMod}
```
