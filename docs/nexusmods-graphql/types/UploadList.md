# UploadList

## Description

A list of upload

## Fields

| Field Name | Description |
| --- | --- |
| `filteredCount` - [Int!](../types/Int.md) | Number of uploads being filtered |
| `totalCount` - [Int!](../types/Int.md) | Total number of uploads |
| `uploads` - [[ModUpload!]](../types/ModUpload.md) | List of uploads |

## Example

```json
{
  "filteredCount": 987,
  "totalCount": 123,
  "uploads": [ModUpload]
}
```
