# GamesSearchSort

## Description

Sort for a list of Games

## Fields

| Input Field | Description |
| --- | --- |
| `downloads` - [BaseSortValue](../types/BaseSortValue.md) | Number of downloads. |
| `mods` - [BaseSortValue](../types/BaseSortValue.md) | Number of mods. |
| `collections` - [BaseSortValue](../types/BaseSortValue.md) | Number of collections. |
| `name` - [BaseSortValue](../types/BaseSortValue.md) | Game name. |
| `approved` - [BaseSortValue](../types/BaseSortValue.md) | Date approved. |
| `relevance` - [BaseSortValue](../types/BaseSortValue.md) | Filter query relevance. |

## Example

```json
{
  "downloads": BaseSortValue,
  "mods": BaseSortValue,
  "collections": BaseSortValue,
  "name": BaseSortValue,
  "approved": BaseSortValue,
  "relevance": BaseSortValue
}
```
