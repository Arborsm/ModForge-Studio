# ModRequirementsDlc

## Description

Represents the DLC (expansion) requirements of a mod

## Fields

| Field Name | Description |
| --- | --- |
| `gameExpansion` - [GameExpansion!](../types/GameExpansion.md) | The game expansion (DLC) required by the mod |
| `notes` - [String](../types/String.md) | Notes about the expansion (DLC) requirement |

## Example

```json
{
  "gameExpansion": GameExpansion,
  "notes": "abc123"
}
```
