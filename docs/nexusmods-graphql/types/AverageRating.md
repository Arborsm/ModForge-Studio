# AverageRating

## Description

Average rating for a single revision and total number of votes

## Fields

| Field Name | Description |
| --- | --- |
| `average` - [Float!](../types/Float.md) | Average rating for this revision |
| `positive` - [Int!](../types/Int.md) | Number of positive votes |
| `total` - [Int!](../types/Int.md) | Total number of votes |

## Example

```json
{"average": 123.45, "positive": 987, "total": 987}
```
