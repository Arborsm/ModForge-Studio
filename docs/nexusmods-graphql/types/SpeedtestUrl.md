# SpeedtestUrl

## Description

A speedtest URL

## Fields

| Field Name | Description |
| --- | --- |
| `description` - [String](../types/String.md) | Description of this speedtest URL |
| `location` - [String](../types/String.md) | URL of the resource |
| `tag` - [String](../types/String.md) | Tag of the resource |
| `title` - [String](../types/String.md) | Resource name of this speedtest URL |

## Example

```json
{
  "description": "xyz789",
  "location": "xyz789",
  "tag": "xyz789",
  "title": "abc123"
}
```
