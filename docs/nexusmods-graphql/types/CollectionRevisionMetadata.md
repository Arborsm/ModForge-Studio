# CollectionRevisionMetadata

## Description

Metadata information about a collection revision

## Fields

| Field Name | Description |
| --- | --- |
| `downloadedAt` - [DateTime](../types/DateTime.md) | A timestamp indicating the first time the user downloaded this revision |
| `ratingValue` - [RatingOptions](../types/RatingOptions.md) | Indicates the rating given by the user to a revision |

## Example

```json
{
  "downloadedAt": "2007-12-03T10:15:30Z",
  "ratingValue": "positive"
}
```
