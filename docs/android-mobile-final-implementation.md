# 安卓移动端终稿实施文档

> 定稿依据：`docs/mockups/android-mobile-final-mock.html`（终版原型，含全部页面与交互流转）+ 本文的设计规范。
> 前序：`docs/android-mobile-ux-overhaul.md`（Phase 1–6 已交付）、`docs/android-mobile-refine*.html`（过程对比稿）。
> 适用范围：仅 Android 宿主（`isAndroidHost()`）；桌面端 >640px 行为与现有实现完全不变。纯样式适配继续走 ≤640px 媒体查询。

## 设计规范（实施硬指标）

1. **触摸目标 ≥48dp**：顶栏/工具图标视觉 38–40px，命中区用 padding/负 margin 补足 48dp。
2. **字号下限 12sp**：正文与卡片 meta ≥12px；辅助信息（时间戳、计数）≥11px，仅限 tertiary 层级。
3. **安全区域**：顶部由原生 `WindowInsetsCompat` 填充（已实现）；底部导航与贴底条消费 `env(safe-area-inset-bottom)`。
4. **颜色**：全部走 `tokens.css` 变量（含深色主题）；禁止硬编码色值。对比度：正文 ≥4.5:1；灰字仅用于辅助信息。
5. **动效**：页面横滑 280ms `cubic-bezier(.32,.72,.28,1)`；底部弹层自下滑入；`prefers-reduced-motion` 时全部禁用。
6. **图标**：统一 lucide，线宽 2，顶栏 16px / 底导 19px。

## 全局架构

- **顶栏（库/发现）**：`[搜索框（页语义 placeholder + 库/发现各自的筛选蓝钮）] [下载][通知][设置]`。brand logo 隐藏；全局动作组在所有顶层页面一致出现（未读徽标、下载进度环保持）。
- **顶栏（更新/诊断）**：`[左对齐标题] … [页专属动作钮] [下载][通知][设置]`。
- **底部导航**：模组库 / 发现 / 更新 / 诊断，4 项目录；soft pill 选中指示。
- **页面栈**：`mobilePageStore` 扩展为 `'downloads' | 'notifications' | 'logs' | 'settings' | 'appearance' | 'mod-detail'`；二级页（设置分类、详情）沿用返回箭头头部；Android 返回键按现有 `android:back` 逐层弹出。

## 实施批次（每批独立提交 + 模拟器截图验收）

### P1 顶栏/页头统一 + 触摸目标

- `TopMenuBar`：androidHost 时隐藏 brand；新增顶栏内嵌搜索槽（`launcherChrome.search`，placeholder 按页注入）；全局动作组（下载/通知/设置）尺寸提到 38px 视觉 + 48dp 命中区。
- 四个顶层页面的 console 头部按新节奏重排：标题/搜索/按钮的层级去卡片化。
- 验收：四页顶栏结构一致；触摸目标 ≥48dp（uiautomator 边界验证）。

### P2 库页

- 搜索框上移顶栏；**筛选面板**（底部弹层）：过滤（全部/已启用/有更新）、排序（名称/更新时间/大小）、显示开关（停用模组、文件夹）——接入现有 sortMenu/隐藏停用状态。
- **贴底启动条**：毛玻璃胶囊（播放钮 + 「启动游戏 / SMAPI 版本 · 模组数」+ 箭头）；点击主体与箭头均打开**启动预检面板**（游戏版本 / SMAPI / 已装模组 / 依赖冲突 / 上次启动，数据来自 `load_launcher_runtime_info` + settings + library scan）；「开始启动」走现有 launch 流程（含版本门槛校验）。
- **下拉刷新**：自实现 `usePullToRefresh`（pointer events + `overscroll-behavior: contain`，圆环 spinner 指示器），触发 `scan_launcher_library` 重扫。
- 工具圆钮退役：功能全部归入筛选面板；安装压缩包按钮保留入口（移入筛选面板「操作」区或空态）。

### P3 发现页

- 搜索框上移顶栏（placeholder「搜索 Nexus 模组…」），右侧筛选蓝钮。
- **筛选面板**：时间/排序/分类/语言/大小 chips 分组 + 应用——接入现有 `DiscoverMenu`（time/sort/pageSize）与 category 筛选状态；页大小固定 20（chip 撤出）。
- **下拉刷新**：重新请求当前页。
- 筛选侧栏整体退役（已有默认收起逻辑，升级为移除）；分页保持极简（prev/next + 页码）。

### P4 更新页

- 顶栏：左对齐标题 + 右侧刷新钮 + 全局动作组。
- 正文：状态行（「N 个模组可更新 · 刚刚检查」+ 全选）→ 勾选行（checkbox + 图 + 名 + 版本对 + 单个「更新」文字钮）。
- **底部「更新所选 N 个」贴底按钮**：随勾选实时变数，走现有批量更新流程；行点击展开详情可选。
- 右键菜单（桌面）在移动端不注册。

### P5 诊断页

- 顶栏：左对齐标题「诊断」+ 右侧「查看日志」文字钮（androidHost → `openPage('logs')`）+ 全局动作组。
- 正文单列保持；确认 SMAPI Update 卡隐藏（已做）；GMCM 探针隐藏（已做）；路径面板仅 Mods/Download 两行（已做）。

### P6 Mod 详情页（三入口共用）

- hero 紧凑定稿：72px 封面 + 名称/作者 + pill（可更新版本、启用状态）；**属性表隐藏**（字段在 Details tab）。
- tabs 下划线式 2.5px；版本条（已装 → 最新 + 更新钮）置于描述下方；元数据一行灰字。
- 底部悬浮胶囊操作栏：文件夹 / 清单 / Update Now（主操作随状态切换：安装/更新/打开）。
- 详情改走页面栈（`mod-detail`）或保持 portal + 全屏样式（现实现），按实现成本二选一，视觉以终稿为准。

### P7 设置两层

- androidHost 下 SettingsWindow 呈现为**页面栈两级**：分类列表页（多色图标 + 名称 + 副标题 + 箭头）→ 二级页（返回箭头 + 该分类 pane）。
- `view` 分类维持隐藏（已做）；分类行图标色：外观紫 / 动效蓝 / 交互绿 / AI 橙 / 开发者红。
- 主题选择改横条式（色块 + 名称 + 选中勾，accent 描边）；语言同构；开关行统一「标题+说明」左、开关右。
- 未保存 AI 守卫逻辑保持。

### P8 二级页面视觉对齐（通知/下载/日志）

- 通知页：未读点、等级图标着色、时间相对化（已实现）；补「清除」为页面头动作钮。
- 下载中心页：行卡（图 + 进度条 + 状态）对齐终稿；底部无 CTA（安装动作在行内）。
- 日志页：保留（已实现）；查看日志入口为诊断页头按钮（已实现）。

### P9 通知 toast 顶部全宽（已实现，复查）

- 顶部全宽横幅、常显关闭、最新一条展示；历史在通知中心页。

### P10 全局收尾

- 48dp 触摸目标全量走查（顶栏/底导/卡片操作/行内按钮）。
- 深色主题全屏截图走查（tokens 无硬编码）。
- 横竖屏旋转、`prefers-reduced-motion` 走查。
- 桌面回归：>640px 截图对比（应零变化）；架构测试 `vp test run` 全量。

## 回归验收清单（模拟器）

1. 冷启动（含持久化 workbench 状态）→ 只进启动器、底导 4 tab。
2. 库页：搜索过滤、筛选面板全项、下拉刷新重扫、启动预检→启动游戏（需真机/游戏环境）。
3. 发现页：搜索（mock+真机双验证）、筛选面板全项、下拉刷新、分页。
4. 更新页：勾选/全选/底部按钮计数联动、单个更新流程。
5. 诊断页：SMAPI 卡隐藏、查看日志页读 LogCapture。
6. 详情三入口（库/更新行/发现卡）全屏页、版本条更新动作。
7. 设置两级导航 + view 分类不可见 + AI 未保存守卫。
8. Android 返回键逐层弹出（页面→弹层→退后台）。
9. 深色主题 + 横屏 + 通知 toast 全宽。
10. `vp run lint` + `vp test run` + `vp run build` 全绿；APK 重建 + CI 绿色。

## 明确不做

- 桌面端（>640px）任何布局变化。
- 工作台模式在安卓的可见性（维持锁定）。
- 底部导航塞功能入口（保持 4 项目录；全局动作在顶栏）。
